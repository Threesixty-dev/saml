# SAML for VS Code

This extension provides syntax highlighting and language-server features for
SAML `.spec` and `.saml` files. It starts the `saml-lsp` binary separately.

Download the VSIX from a
[SAML language release](https://github.com/Threesixty-dev/saml/releases) when
one is available. See the language-server setup guide in the
[SAML repository](https://github.com/Threesixty-dev/saml) for the server binary
and `saml.serverPath` configuration.
